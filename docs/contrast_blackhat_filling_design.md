# 冠脉造影视频怎么选关键帧

这套方法从一段冠脉造影视频里，先找**血管显影比较充分的时段**，再从这些时段里选出最多 **3 张代表帧**。整个过程可以分成四步。

### 1. 先让不同帧的亮度可以比较

把 DICOM 读成一张张灰度图，整段视频用同一套灰度映射，再缩小图像做分析。这样，造影剂进入后血管变暗的变化能保留下来，也能减少计算量。

### 2. 用全图变化找到大致的充盈时段

取视频开头几帧，合成一张背景图。逐帧和背景比较，统计画面整体变暗了多少。把这个变化沿时间平滑，连续至少 3 帧达到门槛的时段，就记为候选充盈区间。

全图变暗也可能来自画面移动或曝光变化。有时后半段的全图分更高，但真正想看的血管在前半段已经显影得更清楚，所以要再看一遍局部血管响应。

### 3. 用局部血管响应校验区间

Black-hat 可以理解成**把比周围更暗的细条纹凸显出来**。造影血管常有这样的外观。算法统计每帧这类结构的面积和强度，剔除很小的孤立响应，再看这种变化是否连续。

- 全图没找到区间时，如果局部找到了，就用局部区间。
- 全图已经找到了区间时，只有在局部找到的时段**全部更早、两段没有重叠**，而且前段的局部血管响应峰值**超过后段的 1.5 倍**，才改用较早的时段。其余情况沿用全图区间。

比如一条序列里，全图找到的是第 **34～54 帧**，局部找到的是第 **9～29 帧**。用同一个局部指标比较，前段的峰值是后段的 **1.74 倍**，所以改在前段选帧，最终选中第 **20 帧**，落在人工标出的 **16～21 帧**内。这里的 **1.5 倍是目前的实验阈值**。

### 4. 给区间内的帧打分，选出代表帧

在最终区间内，再用 Black-hat 给每张图算一个**血管分**。响应较强的区域越多、整张图的平均响应越强，血管分就越高。**充盈分**取自上一步选用的那条曲线，使用全图区间就用全图充盈分，切换到局部区间就用局部充盈分。

```text
总分 = 0.45 × 血管分 + 0.30 × 充盈分
```

两项的相对权重是**血管 60%、充盈 40%**。总分沿时间稍作平滑，再找分数峰值。候选之间至少隔 **5 帧**，同一选帧窗口内画面太相似的也会去掉，所以最后可能只给一两张。没有合适候选时，交给人工复核。

局部响应和血管分衡量的是画面里所有被凸显的血管样结构。**如果主支已经变淡、远端还很清楚，整张图仍可能拿到高分。** 这类情况需要单独评估主支清晰度。
